Unire più file PDF

Funziona nel tuo browser: il file non lascia il dispositivo

Unisce più PDF in un unico documento, nell'ordine in cui li aggiungi. Funziona interamente nel tuo browser, quindi i file non vengono caricati da nessuna parte: cosa che conta parecchio quando si tratta di contratti o referti medici.

Come si fa

  1. Seleziona o trascina tutti i PDF da unire.
  2. Vengono uniti nell'ordine in cui compaiono nell'elenco.
  3. Scarica il PDF unificato.
PUBBLICITÀ

Domande frequenti

I miei file vengono caricati su un server?

No. L'unione avviene dentro il browser e i file restano sul tuo dispositivo.

Quanti posso unirne alla volta?

Tutti quelli che il tuo dispositivo riesce a tenere in memoria. Qualche decina di documenti normali non è un problema.

Segnalibri e collegamenti sopravvivono?

Il contenuto delle pagine e i collegamenti interni a ciascun documento vengono preservati.
