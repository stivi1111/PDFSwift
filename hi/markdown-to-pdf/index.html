Markdown को PDF में बदलें

हमारे सर्वर पर संसाधित और तुरंत बाद हटा दी जाती है

Markdown फ़ाइल को असली दस्तावेज़ की तरह सजाता है: शीर्षक सही क्रम में, कोड खंड एक-चौड़ाई वाली लिपि में, तालिकाएँ सीमाओं के साथ, कड़ियाँ क्लिक करने योग्य।

यह कैसे करें

  1. अपनी .md, .markdown या .txt फ़ाइल अपलोड करें।
  2. Markdown एक सजे दस्तावेज़ में बदलकर PDF में ढाला जाता है।
  3. PDF डाउनलोड करें।
विज्ञापन

आम सवाल

Markdown का कौन-सा रूप समर्थित है?

मानक Markdown और आम विस्तार: तालिकाएँ, घिरे हुए कोड खंड, कार्य-सूचियाँ और कटा हुआ पाठ।

क्या चित्र काम करते हैं?

वेब पते से बताए गए चित्र शामिल होते हैं। आपके कंप्यूटर की फ़ाइलों की ओर इशारा करने वाले चित्र नहीं लाए जा सकते।

क्या कोड रंगीन होता है?

कोड खंड हल्की पृष्ठभूमि पर एक-चौड़ाई वाली लिपि में रहते हैं; भाषा के अनुसार रंग नहीं लगाया जाता।
